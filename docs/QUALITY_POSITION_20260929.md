# 進場位置品質一致性

掃描與進場前更新共用 `entry_location_quality`，依原 Entry 區間與價格偏離評分。
不再以 EMA 延伸程度或 `WAIT_RETEST` 狀態互相替代位置分。
價格位於區間內的位置原始分為 95（加權 28.5 分）；區間外仍依偏離降分。
曾經可進場、等待新的收線回踩確認等歷史旗標，不另扣位置分。

進場前更新另列「收線確認提醒」，只說明最近掃描的確認狀態。
報價更新不重算多週期 K 線，也不創造新的確認證據。
多空方向、正式訊號、終止條件、原始 SL／TP、止損距離與成本評分維持原規則。

評分明細版本升至 2。舊卡原品質保留；新舊版本不計算可歸因差額，
畫面標明「評分方式已更新 · 不直接比較」。重掃後新分數才可同口徑比較。

回歸涵蓋 HUMA 原區間與報價、兩個週期與多空方向、歷史旗標不影響位置分、
區間外降分、已結束計畫、掃描與深度更新共用位置基準，以及舊資料顯示相容性。
