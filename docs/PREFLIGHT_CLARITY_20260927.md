# 進場前更新判讀與回到頂端

本次延續 `ed05906`：進場前更新只更新詳情頁，原列表的價格、交易品質與排序不回寫。

## 畫面與資料

- 列表與更新頁各有一個 44px 的向上按鈕。滑過一個可視區域後顯示；較短頁面滑到底也會顯示。點擊只捲動目前頁面，回到頂端後隱藏。位置依實際內容區計算，避開導覽與更新按鈕；支援減少動態效果、鍵盤焦點與對話框。
- 更新頁區分「原計畫保留，暫停新進場」、「資料不足」及「原計畫已結束」。`NO_FORMAL_TRIGGER` 的說明會依保存的訊號階段區分「未獲延續」及未通過正式觸發標記，保留原阻擋碼與進場權限。
- 右上角維持原品質 → 更新後。評分新增版本化的五項加權貢獻：進場位置、價差、剩餘風險報酬、止損距離、成交成本。計分公式、權重與上限均未改動。
- 只有兩次明細同版本、欄位完整、加總符合各自分數時，才列出影響最大的兩項變化。舊訊號沒有可比明細時只說明本次分項，不推測歷史原因；原計畫結束則另行說明。
- 報價時間直接來自 ticker，成交資料時間來自執行資料，核心判讀時間來自原週期掃描。缺少時間不拿別種資料的時間代替。本次更新不宣稱已重算核心多週期 K 線。
