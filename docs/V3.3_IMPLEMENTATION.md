# V3.3 MASTER 實作對照

本文件把 `OKX_Radar_V3.3_MASTER_完全整合規格` 對照到目前程式。狀態分為：

- **已實作**：已進入正式 V3.3 執行路徑並有測試。
- **刻意隔離**：規格明確列為未來模組，不可成為 Radar 上線前置條件。
- **相容保留**：舊設定／函式仍存在，但不控制 V3.3 Trigger。

## 核心架構

| 規格要求 | 狀態 | 實作位置／行為 |
| --- | --- | --- |

| Trigger 與同向延續確認分離 | 已實作 | 價格／結構與 MA／MACD 仍在既有 Price-first 路徑建立 Trigger；`decision_context.continuation_confirmation` 只對成立後的同向延續證據軟分級 |
| Explainability Score 不能製造 Trigger | 已實作 | `MarketStoryEngine._trigger_candidate` 先判價格布林事實，再計分說明 |

## Context 與微結構

| 規格要求 | 狀態 | 實作位置／行為 |
| --- | --- | --- |
| Participation 只回傳支持／中性／衝突 | 已實作 | `market_participation` 與 permission 標記 |
| OI 本身沒有方向 | 已實作 | 只用 OI change + price 描述建倉／平倉／回補；絕對 OI 非 Trigger Gate |
| Taker 必須對照價格成果 | 已實作 | 同向成交但價格推不動標為可能吸收 |
| CVD 必須對照價格成果 | 已實作 | 同向且有成果才支持；沒成果為吸收 Conflict |
| 延續證據固定三類 | 已實作 | OI、Taker／CVD、核心 K 線量比各為一類；Taker 與 CVD 因同源合併為一票，不能重複加分 |
| 延續結果四級 | 已實作 | `CONFIRMED` 表示至少兩類支持且無方向反證並具完整連續流；證據尚在形成為 `FORMING`，嚴重吸收／反向新增或多域反證為 `CONFLICT`，無明確方向或參與資料不足為 `UNKNOWN` |
| 連續流至少三筆同窗樣本 | 已實作 | Scanner 保存、去除重複 timestamp 後傳入同一比較窗樣本；少於三筆不冒充趨勢，也不能把延續分級升為 `CONFIRMED` |
| Funding／BTC／高週期只降級 | 已實作 | 只加入擁擠、逆市場或逆高週期警告，不是第四類方向票，不直接判方向或取消 Trigger |
| Order Book 需時間序列與 spoof 防禦 | 已實作 | 首張快照不當 S/R；比較撤單、持續、補單、吸收、反向深度 |
| Deep Data 缺失不得刪核心 Trigger | 已實作 | `DATA_MISSING` 降級並保留 Signal |
| 來源 timestamp 與完整度 | 已實作 | `source_timestamps`、available／missing sources、context sampled time |
| 延續分數不是勝率 | 已實作 | `continuation_confirmation.score` 只描述三類證據一致度；Win Rate 仍只能由已完成 Episode 的 TP／SL 與 Final R 樣本計算 |
| 手機卡片首屏資訊分層 | 已實作 | 幣種／週期、方向、目前進場狀態與續走證據置頂；階段與新鮮度降為次要文字，完整判定預設收合 |
| Entry／SL／TP／R:R 四格 | 已實作 | 手機 2×2、寬螢幕 4 欄；TP2 保留在 TP 格，原始計畫與 Episode 規則不變 |
| 三類續走證據列 | 已實作 | 公開 payload 只提供 OI、Taker／CVD、核心量能的安全摘要 `state`／`label`／`detail`，不公開內部 flow 欄位，也不影響進場權限 |
