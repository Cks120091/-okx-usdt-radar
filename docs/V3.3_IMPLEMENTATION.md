# V3.3 MASTER 實作對照

本文件把 `OKX_Radar_V3.3_MASTER_完全整合規格` 對照到目前程式。狀態分為：

- **已實作**：已進入正式 V3.3 執行路徑並有測試。
- **刻意隔離**：規格明確列為未來模組，不可成為 Radar 上線前置條件。
- **相容保留**：舊設定／函式仍存在，但不控制 V3.3 Trigger。

## 核心架構

| 規格要求 | 狀態 | 實作位置／行為 |
| --- | --- | --- |
| 方向、Trigger、強度、Conflict、Execution、歷史績效分離 | 已實作 | `StoryAssessment`、`Signal`、`MarketState` 分欄輸出；Trigger 只取價格事實 |
| Explainability Score 不能製造 Trigger | 已實作 | `MarketStoryEngine._trigger_candidate` 先判價格布林事實，再計分說明 |
| 不新增 AO／ICT／SMC／第二套 HH-HL 競爭引擎 | 已實作 | V3.3 沿用既有 MA／MACD／ATR／結構資料，只新增 Market Story 組織層 |
| 只用已收盤核心 K 線正式觸發 | 已實作 | API 丟棄未收盤 K 線；Strategy 再驗證核心資料 |
| 訊號與下單完全分離 | 已實作 | Report safety 固定 analysis-only；無私人 API 與委託端點 |
