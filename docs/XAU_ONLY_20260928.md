# 僅加入 OKX XAU 黃金永續

## 範圍

- 保留原加密資產掃描清單，額外只接受 `XAU-USDT-SWAP`。
- XAU 必須具備 OKX 商品分類 `instCategory=4`、`state=live`、`settleCcy=USDT`、`ctType=linear`。分類缺失、停牌、反向合約及其他非加密商品仍拒絕。
- 全市場清單與單一合約入口使用相同驗證；XAU 的合約面值、乘數、面值幣種與價格精度來自原始合約資料，沿用於報價／深度／成交資料。
- 搜尋與單幣 API 接受 `XAUUSDT.P`、`OKX:XAUUSDT.P`，也保留 `XAU`、`XAUUSDT`、`XAU/USDT`、`XAU-USDT-SWAP`。不將 Binance 或 Bybit 前綴轉成 OKX 資料。
- TradingView 連結使用 `OKX:XAUUSDT.P`。未更改其他幣的圖表連結。

## 策略與資料

- XAU 參與短線、長線掃描與原有正式／預備分類；不跳過方向、正式觸發、核心資料或生命週期條件。
- 原 24H 成交額 200 萬納入／150 萬移除規則保留。手動單幣掃描沿用流動性提示，不強塞入全市場清單。
- 原計畫成立後可進場前更新，沿用 OKX 報價、持倉與成交資料路徑；缺少輔助資料必須如實顯示，不補造數值。原 Trigger／Entry／SL／TP 不漂移。
- XAU 不計入加密市場 24H RSI、核心平均 RSI、方向分布、加密大盤共振與整體曝險統計；XAU-only 樣本不能宣稱加密大盤中性。
- 對 XAU 不套用 BTC 偏向、加密市場相對強弱或共振加分，標示「黃金獨立觀察」。不修改其他加密資產的原有判斷。
- 商品仍可出現在自身訊號／預備卡、市場地圖與異常資料中，並非從所有畫面隱藏。

## 驗證與限制

- 離線測試覆蓋清單與單幣入口、唯一白名單、合約資料保留、雙週期掃描、市場統計隔離、搜尋代碼、TradingView 連結與既有前端回歸。
- 786 項 Python 測試、20 項 Node 前端回歸、Dashboard／service worker 語法與差異格式檢查通過。
- 此工作環境嘗試 OKX 兩個既有官方 REST 端點時均未取得可解析 JSON，未宣稱已驗證即時 XAU 報價。部署後需以單幣掃描確認當前資料可用性。
- Service worker：`okx-radar-shell-v4.29-xau-only`。

分類依據：[OKX API changelog，2026-04-22 商品分類調整](https://www.okx.com/docs-v5/log_en/#2026-04-22)。
