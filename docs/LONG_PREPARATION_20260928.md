# 長線不同向卡片改列預備

## 問題

長線列表原先收集所有未結束的交易計畫，卡片也一律標示「訊號已觸發」。因此，後端已判定週期方向不同步、禁止新進場的卡片，仍會出現在正式訊號與 80 分以上篩選中。

## 本次行為

- 短線與長線共用列表分類判斷。正式區須有有效觸發階段、最新可用資料、最終 ENTER／允許新進場，且方向確認通過並與卡片方向一致。
- 統一第一層篩選：短線為 4H 背景 → 1H MACD／MA5/10/20 篩選與方向 → 15m 正式 Trigger → 5m 輔助；長線為 1D 背景 → 4H MACD／MA5/10/20 篩選與方向／Setup → 1H 正式 Trigger。1D 僅作背景，不直接決定長線正式方向。
- 長線「接近」頁籤改為「預備」。不同向顯示「預備｜等待同向」，資料不足顯示「待更新｜資料不足」。尚未成立的形態保留在預備區。
- 正式訊號數量、80 分以上篩選、卡片「訊號已觸發」標籤共用相同分類條件。
- 原交易計畫優先於同幣種觀察候選，避免重複卡片。已結束計畫不列入正式或預備區。
- 原 Trigger、Entry、SL、TP 均不改寫；預備卡保留原計畫品質、數據詳情、進場前更新與單幣重掃入口。進場前更新不回寫列表。
- 舊資料若缺少方向確認，不補造同向狀態；重新掃描後依最新判斷分類。
